# 스침 (S:CHIM)

> **Strangers' CHoices In Moments**  
> **Secret Content Hidden In Memories**

**스침은 누군가의 감상이 나를 스치고, 그 순간 새로운 콘텐츠가 열리는 서비스입니다.**

## 서비스 소개

콘텐츠의 제목, 이미지, 평점과 같은 정보를 먼저 보여주는 대신 낯선 사람들이 남긴 감상에서 출발합니다. 사용자는 선입견 없이 감상을 읽고, 마음이 움직인 순간 숨겨진 콘텐츠를 발견할 수 있습니다.

### 한 줄 정의

책·영화·음악·공연·전시·공간 등 콘텐츠의 모든 정보를 숨기고, 낯선 사람들이 남긴 감상만을 통해 새로운 콘텐츠를 발견하는 **블라인드 감상카드 서비스**입니다.

## 주요 기능

- **감상카드 읽기:** 콘텐츠 정보가 가려진 상태에서 낯선 사람의 감상을 탐색합니다.
- **감상카드 등록:** 콘텐츠를 선택하고 자신만의 감상을 작성해 남깁니다.
- **콘텐츠 공개:** 감상을 통해 관심이 생긴 순간 숨겨진 콘텐츠 정보를 확인합니다.
- **아카이브:** 내가 발견하거나 남긴 감상카드를 모아봅니다.
- **온보딩:** 스침의 탐색 방식과 핵심 경험을 안내합니다.

> 현재 프로젝트는 초기 개발 단계이며, 기능 명세는 구현 과정에서 변경될 수 있습니다.

## 기술 스택

- React 19
- JavaScript
- Vite 8
- Tailwind CSS 4
- ESLint

## 시작하기

### 요구 사항

- Node.js 20.19 이상 또는 22.12 이상
- npm

### 설치 및 실행

```bash
npm install
npm run dev
```

개발 서버가 실행되면 터미널에 표시되는 로컬 주소로 접속합니다.

## 명령어

```bash
npm run dev      # 개발 서버 실행
npm run build    # 프로덕션 빌드
npm run lint     # ESLint 검사
npm run preview  # 프로덕션 빌드 미리보기
```

## 프로젝트 구조

```text
src/
├── assets/                 # 이미지, 아이콘, 폰트 등 정적 리소스
├── components/             # 전역 공통 UI 컴포넌트
├── features/               # 핵심 도메인별 모듈
│   ├── surfing/            # 감상카드 읽기
│   │   ├── api/            # 데이터 요청 함수
│   │   ├── components/     # 감상카드 카드와 상세 뷰
│   │   └── hooks/          # 감상카드 관련 커스텀 훅
│   ├── register/           # 감상카드 등록
│   │   ├── components/     # 등록 단계별 UI
│   │   └── hooks/          # 캔버스와 등록 단계 관리 훅
│   ├── archive/            # 아카이브 및 마이페이지
│   │   └── components/
│   └── onboarding/         # 온보딩
│       └── components/
├── hooks/                  # 전역 커스텀 훅
├── pages/                  # 라우트 단위 페이지
│   ├── Home.jsx
│   ├── Register.jsx
│   ├── Archive.jsx
│   └── Onboarding.jsx
├── store/                  # 전역 상태 관리
├── styles/                 # 글로벌 스타일
└── utils/                  # 공통 유틸리티
```
